# زیرنویس‌ساز و مترجم هوشمند فارسی

یک برنامه‌ی دسکتاپ که یک ویدیوی انگلیسی می‌گیرد و هر ترکیبی از این سه خروجی را تحویل می‌دهد:

| خروجی | فایل | توضیح |
|---|---|---|
| زیرنویس انگلیسی | `video.en.srt` | با [faster-whisper](https://github.com/SYSTRAN/faster-whisper) |
| زیرنویس فارسی | `video.fa.srt` | ترجمه با Gemini، همراه با تمایز رنگی اصطلاحات |
| صوت فارسی | `video.fa.mp3` | خوانش فارسی متن، هم‌زمان با ویدیو |

## پیش‌نیازها

- Windows 10/11 (روی لینوکس و مک هم کار می‌کند)
- [Python 3.10+](https://www.python.org/downloads/) — هنگام نصب تیک «Add python.exe to PATH» را بزنید.
- یک یا چند کلید رایگان Gemini API از [aistudio.google.com](https://aistudio.google.com)
- **فقط برای خروجی صوت فارسی**: [FFmpeg](https://www.gyan.dev/ffmpeg/builds/) روی PATH ویندوز

## نصب

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

اگر خروجی صوتی نمی‌خواهید، می‌توانید دو خط آخر `requirements.txt` را نصب نکنید؛ برنامه بدون آن‌ها هم اجرا می‌شود و فقط گزینه‌ی «صوت فارسی» غیرفعال خواهد بود.

## نکات کاربردی

**چند کلید API**: با دکمه‌ی «افزودن کلید جدید» می‌توانید چند کلید ثبت کنید. اگر سهمیه‌ی یکی تمام شود (خطای ۴۲۹)، برنامه خودکار سراغ کلید بعدی می‌رود.

**اولویت مدل‌ها**: مدل‌ها از بالا به پایین امتحان می‌شوند. اگر مدلی حذف یا محدود شده باشد، مدل بعدی جایگزین می‌شود. با دکمه‌های ▲ و ▼ می‌توانید ترتیب را عوض کنید و نام هر مدل دلخواهی را هم دستی تایپ کنید.

**تمایز اصطلاحات**: واژه‌هایی مثل Burp Suite یا Proxy ترجمه نمی‌شوند بلکه آوانویسی می‌شوند («برپ سوییت»، «پروکسی»). این‌ها در زیرنویس فارسی رنگی و بولد نمایش داده می‌شوند تا بیننده بفهمد اصطلاح انگلیسی است نه ترجمه. این حالت از بخش «ظاهر زیرنویس فارسی» قابل تغییر است.

> تگ‌های رنگ در پخش‌کننده‌هایی مثل VLC، MPV و PotPlayer کار می‌کنند. اگر پخش‌کننده‌ی شما تگ‌ها را به‌صورت متن خام نشان داد، حالت را روی «فقط بولد» یا «بدون تمایز» بگذارید.

**صوت فارسی**: در حالت «هم‌زمان با ویدیو» هر جمله دقیقاً سر زمان خودش پخش می‌شود (نیازمند ffmpeg). در حالت «پشت سر هم» جمله‌ها پشت سر هم چیده می‌شوند و نیازی به ffmpeg نیست.

## ساختار پروژه

```
├── app.py                # رابط گرافیکی (tkinter)
├── src/
│   ├── config.py         # ذخیره‌ی محلی کلیدها و تنظیمات
│   ├── transcriber.py    # تبدیل گفتار به متن با faster-whisper
│   ├── translator.py     # ترجمه با Gemini + تمایز اصطلاحات
│   ├── tts.py            # تبدیل متن فارسی به گفتار (اختیاری)
│   └── pipeline.py       # اتصال مراحل و مدیریت خروجی‌ها
├── requirements.txt
└── README.md
```

## عیب‌یابی

- **خطای ۴۲۹ یا اتمام سهمیه**: کلید دیگری اضافه کنید یا چند دقیقه صبر کنید. پلن رایگان Gemini سقف درخواست در دقیقه دارد.
- **«مدل در دسترس نیست»**: گوگل آن نسخه را بازنشسته کرده؛ در بخش اولویت مدل‌ها نام مدل جدید را وارد کنید.
- **کلید نامعتبر / دسترسی ندارد**: اگر کلید درست است، احتمالاً Gemini از منطقه‌ی جغرافیایی شما در دسترس نیست؛ با VPN امتحان کنید.
- **دانلود مدل Whisper گیر می‌کند**: huggingface.co احتمالاً فیلتر است. یک بار با VPN اجرا کنید؛ بعد از آن مدل روی سیستم کش می‌شود.
- **زیرنویس فارسی به‌هم‌ریخته دیده می‌شود**: پخش‌کننده را عوض کنید (VLC یا MPV) یا در بخش ظاهر زیرنویس، حالت «بدون تمایز» را انتخاب کنید.

## هشدار امنیتی

فایل `config.json` کلیدهای API شما را به‌صورت متن ساده ذخیره می‌کند. این فایل در `.gitignore` قرار دارد؛ آن را در گیت یا جای عمومی به اشتراک نگذارید.
